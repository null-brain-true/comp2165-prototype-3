COMP2165 CLICKER - IMPORT INTO A NEW UNITY PROJECT

1. In Unity Hub, create a Unity 6000.3.9f1 Universal 3D project.
2. Import COMP2165_Clicker_Student_Import.unitypackage.
3. Wait for Unity to finish importing and compiling. The package installer creates
   Student Content and its three launchers beside the Assets folder. If these
   files do not appear, choose COMP2165 > Install Student Content.
4. Open Assets/Resources/Scenes/Clicker.unity and press Play.
5. Edit the CSV, image and audio files in Student Content without opening Unity.
   Save Canvas or code edits in Unity before building.
6. Double-click Student Content/Run Student Build.bat to make the WebGL ZIP.
   Unity's WebGL Build Support module must be installed.

The launcher builds a cached copy, so the Unity Editor can stay open.
Read Student Content/START HERE.txt for data and media editing instructions.
