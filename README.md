# COMP2165 Assessment 3 Clicker

This project is a Unity 6 idle clicker template. Students change game data in the eight CSV files under **Student Content**, and replace images/audio under **Student Content/Media**. They do not need to open the Unity Editor for a reskin. The launchers in Student Content copy these files into Unity; the build launcher runs the editor in background batch mode. The optional workbook can export seven of the CSV files. The project uses the MIT-licensed [uClicker](https://github.com/philipcass/uClicker) economy library and a CSV-driven adapter.

To give students a fresh-project import, use `Builds/COMP2165_Clicker_Student_Import.unitypackage`. Import it into a Unity 6000.3.9f1 Universal 3D project. The package includes the scene, scripts, sample media and a seed archive; its installer creates `Student Content` and the launchers beside `Assets`. If needed, choose **COMP2165 > Install Student Content**. Open `Assets/Resources/Scenes/Clicker.unity` after importing.

## Editing the Canvas layout (instructor option)

Open `Assets/Resources/Scenes/Clicker.unity` in Unity and expand **Editable Clicker Canvas** in the Hierarchy. Move and resize its Header, Cookie Panel, Shop Panel, Event Overlay, and Notification with the Rect tool. The Canvas Scaler is set to a 1280 × 720 reference size. The two disabled objects named **Building Row TEMPLATE** and **Upgrade Row TEMPLATE** control how every shop row looks when the game runs; edit their icon, text and button layout in the Scene. The Event Overlay and Notification are also disabled until needed in Play mode, so temporarily enable them in the Hierarchy to edit their positions, then disable them again.

The Canvas layout is a Unity scene asset. Images come from `Student Content/Visuals.csv`; events and text come from the other CSV files. If this Canvas ever needs rebuilding, use **COMP2165 > Create Editable Canvas**; the command leaves an existing Canvas in place.

Panel and font colours are editable in `Student Content/Palette.csv`. Change a `hex` value using `#RRGGBB` or `#RRGGBBAA`; the final two digits set opacity (`FF` is fully opaque, `80` is about half). The `text_primary` value sets regular text; `text_title`, `text_secondary`, `text_button`, `text_notification`, and `text_tooltip` set those specific groups. `tooltip_panel` colours the hover tooltip. The build launcher copies this CSV into the game. To preview changed colours in the Unity editor, choose **COMP2165 > Apply Palette CSV to Canvas**.

## Student workflow

1. Edit `Settings.csv`, `Currencies.csv`, `Buildings.csv`, `Upgrades.csv`, `Events.csv`, `Visuals.csv`, `Audio.csv`, and `Palette.csv` in `Student Content`. Keep the header row unchanged and IDs unique.
2. Put replacement `.png` or `.jpg` images and `.wav` audio in `Student Content/Media`. Use WAV for browser music and sound effects; Unity WebGL does not play streamed OGG music through this template. Enter paths relative to that Media folder in `Visuals.csv` and `Audio.csv`. For example, `images/new-cookie.png` means `Student Content/Media/images/new-cookie.png`. Blank paths use the built-in visual fallback or silence. `Palette.csv` controls panel and font colours.
3. Double-click `Student Content/Refresh Student Content.bat` to copy CSV and media changes into the Unity project. Save any Unity scene or code edits, then double-click `Student Content/Run Student Build.bat` to make the WebGL ZIP. The Unity Editor can stay open; the launcher builds from a cached copy. The first build can take a while; later builds reuse Unity imports and compiled files. Unity 6000.3.9f1 with WebGL Build Support must be installed. The build also refreshes content automatically and creates `Builds/COMP2165_Clicker_itchio.zip` and `Builds/WebGL`.

To play locally, extract the entire ZIP, then double-click `Play WebGL.bat` inside it. Keep its window open while playing. Submit the ZIP with the launcher included so the marker can run it locally.
   If you prefer Excel, edit and close `Student Content/Clicker Template.xlsx`, then double-click `Student Content/Export Workbook CSVs.bat`. This overwrites the seven gameplay CSVs from the workbook and refreshes the project. It does not overwrite `Palette.csv`. A normal refresh or build never exports the workbook.
4. On itch.io, create an HTML game, upload the ZIP, select **This file will be played in the browser**, and publish. Share the playable URL on the Week 10 forum.

`Currencies.csv` defines each currency's ID, display name, starting balance, and amount earned per cookie click. The first row is the main currency. Buildings choose their payment and production currencies with `cost_currency` and `yield_currency`; upgrades choose a `cost_currency`. `unlock_currency` controls which currency's lifetime earnings satisfy `unlock_at`, and defaults to the cost currency. For `click` and `all` upgrades, `target_id` is a currency ID; a blank target uses the main currency. Saved progress keeps balances and lifetime totals by currency ID, including compatibility with older single-currency saves.

`Events.csv` contains the five required fields: Event Title, Event Description, Event Option 1, Event Option 2 and Correct Option. Set Correct Option to `1` or `2` for a fixed successful button, or `0` to randomly select the successful button each time that event card is added to the stack. The button text and positions stay fixed; the result is chosen once per card, not again when clicked. Image and Sound are optional. `Currency` chooses which currency an incorrect answer deducts, and defaults to the main currency. Events accumulate in a stack, can be opened and closed, and resolve from the top. Each correct answer gives a multiplier equal to **10 × the Golden Cookie multiplier** for the same duration. Correct event bonuses and the Golden Cookie bonus stack multiplicatively. Golden Cookie and event timing, costs, production and labels are all editable in the CSV files.

The game saves progress in browser storage using Unity PlayerPrefs. A browser can clear this storage. The project includes original sample text and the icon atlas supplied by the project owner.

## Shop and sample media

Buildings and Upgrades appear together in one shop panel, with separate scroll areas. The sample has 6 buildings and 22 upgrades, including a Sugar Mill and two Sugar-priced upgrades; distant locked items stay hidden. Choose BUY or SELL and a batch of 1, 10 or 100 for buildings. The sale return is controlled by `sell_refund_percent` in Settings (50% by default).
The `tooltip` column in `Buildings.csv` and `Upgrades.csv` controls each item's hover popup. Leave a cell blank to hide that item's tooltip. The tooltip panel is part of the Canvas and can be styled in Unity.
New items appear when lifetime earnings in their cost currency reach `shop_reveal_percent` of their price (50% by default). Items still below their `unlock_at` value in their unlock currency appear locked until that value is reached. The starting Cursor is always visible, and owned items remain visible. You can change the reveal percentage in Settings.

The sample atlas is available at `Student Content/Media/sheets/cookie_clicker_icons.png`. In `Visuals.csv`, change the `sprite_sheet` row's `path` to a new atlas in that folder. Its `tile_size` is 48 by default. Each image row uses a zero-based `sprite_column` and `sprite_row`, counted from the top left. To use an individual PNG instead, put its relative path under `path` on that image's row; a nonblank path takes priority over the sheet coordinates. `Assets/Resources/SpriteSheets/IconMap.csv` controls optional extracted PNG copies and Canvas edit-mode previews for instructors. Background art is blank in the sample. The supplied atlas's redistribution permissions have not been verified; check them before publishing a build. Sample interface sounds are from Kenney under CC0 and the looping music is "Flowerbed Fields [Loop]" by Zane Little Music under CC0. See `Student Content/Media/ASSET_SOURCES.md` for details.
